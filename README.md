## Description

Riv'dle is a emoji-based guessing game where you try to guess the location of what we are describing based off of the emojis we display. For each guess you get wrong, we provide one more hint until you have 3 emojis. Then you will guess the location we are describing
What it does and what problem it solves

## What it does

Its a emoji-based guessing game where you input locations and for each new hint it gives, you re-adjust your thinking and try to learn more.

## What problem this game helps with

This game helps new students and people unfamiliar with the campus to learn about the locations and what the buildings could possibly be used for and where it could be on campus.
